# PortTide

Локальный менеджер прокси-подписок для Windows: работа в фоне, значок в трее и веб-панель.

> Этот README описывает текущую ветку разработки. Установка, трей и обновления ещё не входят в опубликованную `0.1.0-alpha.2`.

PortTide работает только в режиме **прокси**. Направлять через него трафик нужно внешними средствами: например, ZeroOmega в браузере, Clash Verge или настройками самого приложения. **Фильтрация трафика не настроена:** выбор сайтов и приложений, использующих прокси, остаётся на стороне внешних средств.

## Запуск

1. Установите Windows x64 сборку. Программа устанавливается для текущего пользователя; права администратора не требуются. При установке можно выбрать автозапуск и ярлык на рабочем столе.
2. Откройте PortTide через ярлык в меню «Пуск», на рабочем столе или значок в трее. Панель доступна на `http://127.0.0.1:17790`.
3. Добавьте HTTPS-ссылку на подписку либо импортируйте JSON-файл. Поддерживается незашифрованный Xray JSON: один конфиг или массив конфигов. User-Agent можно изменить; по умолчанию используется `Happ/2.0.0`.
4. Выберите профиль и нажмите «Подключить». При необходимости проверьте задержку, скорость и выходные IP.
5. Укажите в своём приложении HTTP или SOCKS5-прокси `127.0.0.1:17890`. Логин и пароль находятся в настройках прокси.

ZIP остаётся дополнительным вариантом: распакуйте его целиком, сохранив папку `core`. Для явного открытия панели запускайте `PortTide.exe --open`. Перемещение ZIP-папки требует заново включить автозапуск в настройках; установщик использует постоянный путь.

По умолчанию используется mixed-порт с авторизацией. В Mixed отображается один порт; в раздельном режиме — SOCKS5 и HTTP. Mixed и SOCKS5 используют одно сохранённое значение, отдельный HTTP-порт сохраняется независимо и не сбрасывается при переключении. В новых настройках он пустой, пока его не зададут. Уже сохранённые значения сохраняются. Все входы доступны только с этого компьютера. Штатный SOCKS-вход Xray также принимает HTTP в режиме раздельных портов; отдельный HTTP-вход просто даёт второй адрес для клиентов.

PortTide не включает системный прокси, TUN, не меняет DNS, firewall, правила Clash или маршрутизацию Windows. Он выдаёт локальный прокси; дальнейшее использование определяется другими приложениями.

## Работа в фоне

В разделе **«Приложение»** три независимые настройки:

- **Запускать при входе в Windows.** При установке опция предложена включённой; в ZIP включается вручную.
- **Запускать прокси вместе с PortTide.** По умолчанию включено. Используется последний профиль, затем первый поддерживаемый из той же подписки, затем первый в общем порядке подписок. Названия профилей не влияют на выбор. Ошибка соединения не переключает страну.
- **Запускать в фоне.** По умолчанию включено. Браузер автоматически не открывается; ярлык с `--open` и команда трея открывают панель явно. Первый обычный запуск без подписок открывает настройку.

Закрытие вкладки оставляет приложение работающим. «Остановить прокси» действует только в текущем сеансе и не меняет настройку следующего запуска. Для полного выхода используйте меню трея или **«Приложение → Завершить PortTide»**. Повторное открытие через ярлык использует уже работающий экземпляр.

Прокси запускается из сохранённого конфига; подписки обновляются отдельно в фоне. Состояние «Прокси запущен» означает готовность локального входа. Доступность интернета проверяется отдельно. После перезапуска приложения панель восстанавливает связь автоматически.

## Обновление PortTide

В разделе «Приложение» можно проверить новую версию, открыть описание и нажать «Обновить и перезапустить». Фоновая проверка выполняется после запуска и раз в сутки; установка всегда запускается пользователем. Для alpha-версий учитываются предварительные выпуски; стабильная версия предлагает стабильные обновления.

Установщик сначала скачивается и проверяется по SHA-256 из официального GitHub Release. Только затем останавливается PortTide. Во время установки соединения через прокси прерываются. После обновления восстанавливается прежнее состояние: работающий прокси запускается, остановленный остаётся остановленным. Панель сама переподключается. Автоматическая установка из экземпляра с отдельным `--data-dir` недоступна.

Программа устанавливается в `%LOCALAPPDATA%/Programs/PortTide`, а настройки хранятся отдельно. Обновление сохраняет подписки, пароль, порты, выбранный профиль, ярлыки и автозапуск. Перед обновлением создаётся `settings.before-update.json`; при переходе со старой схемы также сохраняется `settings.v1.backup.json`. Комплектное ядро обновляется вместе с приложением. Внешний Xray по указанному вручную пути не заменяется.

Можно запустить новый установщик вручную поверх предыдущей установки. При первом переходе с старого ZIP `0.1.0-alpha.2` сначала завершите старый PortTide через его настройки. Удаление приложения сохраняет данные по умолчанию; удалить их можно отдельным выбором в окне удаления.

## Что показывают проверки

- **Задержка** — прогрев и семь HTTPS-замеров к gstatic через выбранный профиль с повторным использованием соединений. Показываются медиана, диапазон, колебания и число успешных ответов. Это не ICMP ping.
- **Скорость** — четыре параллельных потока через Cloudflare: отдельный прогрев, затем до 20 секунд измерения в каждом направлении. Размер одного запроса ограничен 4 МиБ, общий объём с прогревом — 1 ГиБ на направление. Прогрев исключён из результата; отдача считается по передачам с подтверждённым завершением. При раннем достижении лимита или ошибке отображается причина.
- **IP и география** — Cloudflare и ipify показывают видимый им IP. Для каждого полученного адреса отдельно запрашиваются ipwho.is и ipapi.co. Страна, город, ASN и организация могут различаться между источниками. Ошибка или ограничение сервиса отображаются явно.

Проверки открываются в боковой панели; после закрытия сохраняется позиция в списке. Флаги встроены в приложение как SVG, а описание подписки, легенда эмодзи, срок и трафик показаны под заголовком «Профили».

Для каждой проверки создаётся отдельный временный Xray с собственным портом. Рабочее подключение не переключается. Одновременно выполняется одна проверка, её можно отменить. Скоростной тест расходует общую полосу соединения. Последние результаты пока хранятся только в текущем сеансе приложения.

Названия, флаги, эмодзи и описания берутся из подписки и отражают заявления поставщика. Они не заменяют результат проверки. Серверные правила VPN могут давать разные выходные IP для разных сайтов даже у одного фиксированного профиля.

## Подписки и обновления

Можно добавить несколько источников и заменить ссылку без пересборки программы. Поддерживаются конфигурации до 4 MiB и 512 записей. Другие форматы, зашифрованные подписки, URI/base64, Clash YAML и sing-box JSON пока не поддерживаются.

При ошибке обновления сохраняется кеш. Если активный профиль исчез или стал неподдерживаемым, обновление отклоняется до его остановки. Изменившаяся конфигурация активного профиля перезапускает только Xray PortTide и может оборвать его старые соединения. При неудачном запуске выполняется попытка восстановить предыдущий процесс. Статус «запущен» подтверждает готовность локального входа; сеть проверяется отдельной кнопкой.

PortTide создаёт собственные входы и пользовательский маршрут через выбранный прокси. Поддерживаемые транспорты, цепочки и балансировщики сохраняются. Пользовательские DIRECT/REJECT-правила поставщика не импортируются; DIRECT допускается для ограниченного внутреннего DNS bootstrap. DIRECT fallback и отключённая проверка TLS отклоняются.

## Данные и перенос

Настройки находятся в `%LOCALAPPDATA%/PortTide`:

- `settings.json` — ссылки, параметры прокси, выбранный профиль;
- `cache.json` — приватные конфигурации из подписок;
- `porttide.log` — сообщения запуска приложения.

Эти файлы содержат секреты. В GitHub и архив для друга они не входят. Друг получает чистый установщик или ZIP и вводит собственную подписку. Для переноса своих настроек копируйте приватный каталог только на своё устройство при остановленном PortTide.

Можно заранее создать `settings.json` по примеру `examples/settings.json`. Пропущенные идентификаторы и пароль локального прокси генерируются при первом запуске. `corePath` оставляйте пустым, если используется комплектное ядро: это позволяет перемещать папку программы.

Для изолированного запуска предусмотрены `--data-dir ПУТЬ`, `--listen 127.0.0.1:ПОРТ`, `--core ПУТЬ`, `--open`, `--background`, `--no-browser`, `--version`.

## Пример подключения внешнего клиента

В Clash или другом клиенте добавьте локальный SOCKS5-прокси с адресом, портом и авторизацией из PortTide и включите его в нужную группу. Если используется TUN, исключите фактический путь `core/xray.exe` PortTide из перехвата, иначе возможна петля. Программа не редактирует эти правила автоматически и не заменяет существующую схему подключения.

## Разработка и лицензия

Сборка: Go из `go.mod`; упаковка и получение ядра: Python 3.12+. Пользователю готовой сборки они не нужны. Инструкции разработчика находятся в [README.md](README.md). CI проверяет Windows нативно и запускает race detector в Linux на синтетических локальных соединениях; настоящая подписка не требуется.
