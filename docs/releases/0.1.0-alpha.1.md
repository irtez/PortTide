First Windows x64 alpha of PortTide, a local proxy subscription manager.

- Import HTTPS or local-file Xray JSON subscriptions with profile names, emoji and available subscription metadata.
- Choose a profile and expose an authenticated loopback mixed HTTP/SOCKS5 port or separate client ports.
- Run isolated latency, bounded throughput and IP/geography diagnostics; show observer and database results separately.
- Preserve cached profiles on failed refresh, validate changes with Xray, and restore the prior runtime after failed startup.
- No system proxy, TUN, firewall or routing changes.

Extract the portable ZIP completely and run PortTide.exe. Documentation is included in Russian and English. The default UI address is http://127.0.0.1:17790 .

This is an early alpha: encrypted and non-Xray subscription formats are not supported, results last for the current session, and Windows auto-start/tray integration is not included. Native Windows and Linux integration tests use local endpoints; live upstream throughput/geography validation remains pending. See docs/validation.md for precise coverage.

The bundle contains no subscription or account credentials. PortTide uses MIT; Xray retains MPL-2.0 with its corresponding source reference.
