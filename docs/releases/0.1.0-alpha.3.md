PortTide теперь удобнее для повседневного использования в Windows: установщик, трей, тихий автозапуск и обновления из приложения.

### Что изменилось

- Добавлен установщик для текущего пользователя, ярлыки в меню «Пуск» и на рабочем столе. ZIP остаётся доступен.
- Добавлен трей: открытие панели, запуск/остановка прокси, настройки и выход. Повторный запуск открывает существующий экземпляр.
- Настройки запуска Windows, подключения прокси и фонового режима разделены. Фоновый режим включён по умолчанию. «Остановить» действует только в текущем сеансе.
- При запуске выбирается последний профиль либо первый поддерживаемый в порядке подписок. Названия вроде «Автовыбор» не имеют специального значения.
- Добавлены проверка новых версий и загрузка установщика с проверкой SHA-256. Обновление сохраняет настройки, авторизацию и работающее/остановленное состояние прокси.
- Упрощён экран профилей: информация и легенда эмодзи из подписки, встроенные флаги стран, компактный статус подключения. Исправлено выравнивание поиска, счётчик получил понятную подпись.
- Проверки перенесены в боковую панель. Уточнена методика задержки и скорости: прогрев, несколько замеров/потоков, отдельная статистика и понятная подпись лимита теста.
- Mixed показывает один порт; переключение режимов сохраняет введённые значения.
- Открытая веб-панель автоматически восстанавливает связь после перезапуска приложения.

### Установка и переход с alpha.2

Скачайте **PortTide-0.1.0-alpha.3-windows-x64-setup.exe**. Перед первой установкой поверх использования старого ZIP завершите alpha.2 через его настройки. Подписки и параметры из `%LOCALAPPDATA%/PortTide` сохраняются; перед миграцией создаётся резервная копия. При удалении приложения данные сохраняются по умолчанию.

PortTide предоставляет только локальный HTTP/SOCKS5-прокси. Направление и фильтрация трафика настраиваются во внешнем клиенте, например ZeroOmega или Clash Verge. Системный прокси и TUN не включаются.

Это предварительный выпуск. Поддерживаются незашифрованные Xray JSON-подписки; другие и зашифрованные форматы пока не поддерживаются. Скоростной тест может использовать до 2 ГиБ суммарно.

Установщик, обновление работающего/остановленного прокси и удаление проверены на изолированной Windows-установке. Подробности проверок: [docs/validation.md](https://github.com/irtez/PortTide/blob/v0.1.0-alpha.3/docs/validation.md).
